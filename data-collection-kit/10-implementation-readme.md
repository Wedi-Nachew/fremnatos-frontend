# Fremnatos Data Collection Kit — README

## How to Use This Kit

1. Start with `01-general-information-form.md` — it unlocks all other forms.
2. Assign each questionnaire to the relevant staff member listed at the top of each file.
3. Return completed forms to the Communications Lead.
4. The Communications Lead enters answers into the Master Spreadsheet (`09-master-data-spreadsheet.md`).
5. Every photo, video, or personal story requires a signed `08-consent-form-template.md`.
